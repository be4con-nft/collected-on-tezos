# Collected on Tezos

Monthly stats of art collected through Tezos marketplaces (paid sales only).

- Live data: [`data/monthly.json`](./data/monthly.json)
- Archive copy also lives in Google Drive folder **Tezos Art Stats**
- UI is a separate Grok Build app that fetches `monthly.json` from this repo

When data is updated in this repo, the published app should reflect it on the next load (cache-bust the fetch URL).
